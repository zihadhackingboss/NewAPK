# 📱 Keyboard Mod Package

This directory contains the ready-to-test APK and configuration JSON for **AI Smart Keyboard (Android 15 / 16)**.

## 📁 Files in this Directory

- **`keyboard_mod.apk`** / **`app-debug.apk`**:
  The compiled Android application package for Android 15 (API 35/36, minSdk 26).
  - All 6 themes unlocked
  - Dual Mode (English + Bangla translation)
  - Online AI translation (Gemini 3.5 Flash) + Offline translation fallback
  - Voice typing & speech recognition
  - Unlimited clipboard history & pinning
  - Custom dictionary shortcuts
  - Zero ads, no paywalls

- **`keyboard_mod_config.json`**:
  The configuration profile detailing all unlocked features, themes, and dictionary presets.

## 🚀 Installation & Testing

1. Download `keyboard_mod.apk` directly to your Android device or emulator.
2. Install the APK (enable "Install unknown apps" if prompted).
3. Open the app and follow the 2-step setup:
   - Tap **"1. Enable Keyboard in Android Settings"** → Enable **AI Smart Keyboard**.
   - Tap **"2. Switch Default Keyboard"** → Select **AI Smart Keyboard**.
4. Use the in-app test area or open WhatsApp, Telegram, Notes, or Messages to type in English, Bangla, or Dual Mode.
